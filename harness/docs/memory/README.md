# Memory

Memory is a cache, not an archive (`AGENTS.md` Part A, section 7). It holds pointers, preferences and why-history that an agent must know before it reads anything else. No fact lives only here; the Authority line points at the owner.

## A page

```
---
name: <kebab-case, equals the file name>
description: "<one line; becomes the index line>"
metadata:
  type: user | feedback | project | reference
reviewed: true      # optional: a human hand-edited this; revise around it, never overwrite it
---

**Fact:** <the pointer or preference, one to three sentences>

**Why:** <why it matters; the incident or decision, with a date>

**Authority:** <path> | <path#heading> | ADR-NNNN   (several separated by ;)
```

Body under 800 bytes unless `reviewed: true`. A restated rule does not fit, by design. `MEMORY.md` is generated by `python scripts/harness_lint.py --rebuild-index`; never hand-edit it.

## Rules

- Write-back: an answer that took real digging is filed here before the session ends. A synthesis not persisted did not happen.
- Revise in place. Never add a dated page beside a wrong one.
- Vendor auto-memory (Claude's, Antigravity's) is not a store of record. At `harness-close` step 7 anything durable in it is promoted into a page here.
- When a feature is retired, its pages go in the same change.
